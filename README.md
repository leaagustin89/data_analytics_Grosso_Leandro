# RetailPro - Data Analytics

Repositorio de entregas del proyecto RetailPro.

## Estructura

- `modulo_3/`: archivos del módulo 3.
- `Modulo_4/m4_consultas_negocio.sql`: consultas de negocio.
- `Modulo_5/m5_consultas_joins.sql`: consultas con JOINs.
- `Modulo_6/RetailPro_ETL_Grosso_Leandro.pbix`: proyecto de Power BI.
- `Modulo_6/RetailPro_ETL_Evidencias_Grosso_Leandro.pdf`: registro del proceso y evidencias del ETL.
